# Мой учебный / хобби-проект

- **Название проекта**: Task Tracker CLI & Web
- **Стек технологий**: Python, FastAPI, Docker, PostgreSQL
- **Краткое описание**: Утилита командной строки и веб-интерфейс для отслеживания учебных дедлайнов и задач с автоматическими напоминаниями.
- **Планы по развитию**: Добавить интеграцию с Telegram-ботом и настроить CI/CD пайплайн для автодеплоя.
